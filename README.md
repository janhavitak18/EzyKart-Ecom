# 🛒 EzyKart – E-commerce Platform

EzyKart is a responsive and user-friendly e-commerce website built using **React.js** for the frontend and **MongoDB** for the backend. It offers a seamless shopping experience with powerful product filtering, cart management, and secure payments via **Stripe**.


---

## 🚀 Features

- 🛍️ Browse 100+ products across categories
- 🔍 Advanced search & filter by category, price, size, and color
- 🛒 Add to cart, update quantity, and remove items
- 💳 Secure payment integration with **Stripe**
- 📱 Fully responsive UI across all devices
- 🔐 Authentication & route protection (optional future upgrade)

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- HTML5 + Tailwind css
- JavaScript (ES6+)
- Axios (for API calls)

**Backend:**
- MongoDB (NoSQL Database)
- Express.js

**Others:**
- Stripe (Payment Gateway)
- GitHub (Version Control)
- Vite (React bundler)

#1. Clone the repository
```bash
git clone https://github.com/janhavitak18/EzyKart-Ecom.git
cd EzyKart-Ecom
```
2. Install dependencies
```
npm install
```
4. Start the development server
```
npm run dev
```
4. Backend Setup (optional if not integrated in this repo)
Set up a basic Express server with MongoDB connection for handling product data and cart.
